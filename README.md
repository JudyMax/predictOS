# pdx 앱 온보딩·배포 프로토타입

원프레딕트 PM 사전과제용 인터랙티브 프로토타입입니다. 통합 기획안의 핵심 시나리오 **흐름 1 (새 버전 등록 → 검토·승인 → 공장별 배포 → 정상 동작 확인)**을 시작부터 종료까지 구현했습니다.

- 역할 인계: Application Manager(등록·재제출) ↔ Platform Admin(검토·승인·배포). 헤더의 역할 전환과 상단 시나리오 가이드로 진행합니다.
- 예외 상태: ② 승인 반려 → 사유 확인 → 재제출, ④ 버전 충돌로 공장 B(v1.0.3) 배포 차단
- 화면: 앱 버전 관리(등록 드로어), 버전 상세·검토(반려 모달), 배포 관리(공장 선택 → 사전 환경 검증 → 부족 항목 채우기 → 실행·정상 동작 확인), 공장 화면

## 실행

```bash
npm install
npm run dev
```

Vite + React + TypeScript. 서버 없이 브라우저 상태만으로 동작하며, 새로고침하면 처음 상태로 돌아갑니다.
